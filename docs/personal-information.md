# v0.1.6 个人信息与个性化面试答案

## 使用

1. 打开侧栏「个人信息」，选择简历、面试讲稿或项目材料，上传 PDF、DOCX、TXT、Markdown。
2. 在「我的资料」按类型筛选并选择一份资料，直接预览提取正文；上传入口默认折叠，首次使用自动展开。文字提取不会调用云端模型，也不上传 OSS。
3. 在「生成偏好」填写目标岗位、可选岗位描述，选择回答长度，勾选「生成高分答案时使用个人资料」并保存。
4. 打开「问答知识库」或「面试详情」，点击生成或重新生成高分答案。开启个性化后，相关个人资料片段、岗位描述和相关历史面试问答会发送至 DeepSeek。
5. 查看答案中的引用及「个人资料参考依据」。缺少的经历标记待补充，资料冲突由模型提示并需本人确认。生成不会覆盖面试原答。

资料区域只显示当前选中的一份，下载和启停在正文下方；版本详情及删除确认收在「版本信息与删除」中。问答与任务每页最多 8 条，搜索结果改变时自动回到首页。

## 文件与版本

- 单份最多 10 MB、20 万字符，最多保存 50 份。PDF 最多 100 页，需未加密且含可提取文字；图片或扫描件请先 OCR。DOCX 读取正文和表格，旧 DOC 需另存 DOCX；TXT/Markdown 使用 UTF-8。
- 新简历自动停用旧简历，同时最多启用一份简历。讲稿和项目材料可同时启用多份，可单独停用、下载、删除。重复文件按分类拒绝。
- 每次上传产生独立版本 ID；更新资料不改写旧答案。旧答案保存生成时的参考快照、目标岗位、回答长度和模型引用，需重新生成才能使用新资料。
- 删除原资料会删除原文件、提取正文和检索分段；已生成答案中的快照，以及已导出的笔记和历史备份仍保留，需分别清理。
- 原文件、正文、分段、个人偏好均保存在本地 `app.db`。程序的数据库备份涵盖这些个人资料；完整面试备份仍需保留整个数据目录。请勿将真实资料加入源码或发布包。

## 检索与生成边界

首版采用本地关键词检索：中文双字词与英文技术词分词，BM25 风格评分，问题权重大于岗位描述。无需额外向量模型、API Key 或向量数据库。它属于方案三的文档分段、检索、证据生成流程，但不具备语义向量检索能力；同义改写、无共同关键词的问题可能漏检。

正文按 900 字符窗口、700 字符步长切分。每次最多提供 8 个资料片段、每份最多 3 个；当前简历前两个片段作为概况候选。引用保存文件名、版本 ID、片段编号和原文。程序验证模型返回的引用 ID 是否属于本次检索结果，不能自动证明模型每一句话都得到原文支持，请核对。

历史复盘从最近 100 条有效问答中选择最多 3 条有共同词的问题，每条原答最多 1200 字符，仅作复盘依据，不直接视为已确认的个人事实。停用的个人资料不会进入新的检索；历史生成的 AI 高分答案不进入经历检索。

回答长度是提示词目标，不代表精确计时。事实约束、冲突提示均有模型能力限制，不能保证发现未命中片段中的冲突。没有开启个性化时保持原生成流程，不发送个人资料；开启但资料不足时提示待补充。

## 验证

新增测试覆盖 PDF/DOCX/文本提取与限制、简历版本启停、重复导入、相关性检索及长度约束、删除与备份、引用校验和生成失败保留旧答案、个人信息页的偏好与删除流程。测试使用模拟模型，不使用真实简历或付费调用。
