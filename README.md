# 面试录音整理助手

Windows 本地应用，使用阿里云 ASR 转写录音、DeepSeek Flash 整理问答，SQLite 和 Markdown 保存到本机。

## 启动

双击 `start.cmd`，或在本目录运行：

```powershell
.\start.ps1
```

首次启动使用已安装的 Python 3.13 创建本项目 `.venv`，安装锁定依赖，然后启动网页和独立后台。默认地址为 http://127.0.0.1:8501 。关闭启动进程后后台停止；下次启动从已保存检查点恢复。只关闭浏览器页面不会停止后台。

双击 `stop.cmd` 可停止本项目启动的网页和 Worker，保留本地数据与任务检查点。后台当前请求可能已在云端执行，停止本地进程不保证撤销云端计费。

其他启动方式：

```powershell
# 已有 Python >=3.11 虚拟环境
python -m pip install -e '.[dev]'
python run.py --headless --port 8501

# 自动化测试，不调用付费服务
python -m pytest -q
```

## 密钥与转写配置

应用读取系统环境变量，不需要把密钥写入文件：

| 变量 | 用途 |
| --- | --- |
| `AliApiKey` | 千问/阿里云 ASR |
| `deepseek` | DeepSeek 问答整理 |
| `OSS_ACCESS_KEY_ID` | 私有 OSS 上传、读取、清理使用的独立凭据 |
| `OSS_ACCESS_KEY_SECRET` | OSS 凭据对应的 Secret |
| `OSS_SESSION_TOKEN` | 可选的临时 OSS 凭据 Token |

后端优先读取进程环境；Windows 密钥缺失或格式无效时继续查找用户环境、系统环境中的有效格式值。显式空进程变量会禁用回退；格式有效不代表鉴权成功，鉴权失败不会自动轮换密钥。界面只显示是否读取成功。

变量值必须是 API Key 本身，不能含中文说明、空白或控制字符。读取成功仅代表变量存在，设置页会单独提示格式问题；鉴权是否成功由真实请求验证。

「设置与数据」页面配置 OSS bucket、HTTPS endpoint（如 `https://oss-cn-beijing.aliyuncs.com`）；也可使用 `ASR_STORAGE_BUCKET`、`OSS_ENDPOINT` 系统环境变量。环境变量优先于页面配置。模型 Key 不能代替 OSS AccessKey。

默认模型与地址：

- ASR：`qwen-audio-3.1-asr-flash-filetrans`，`https://dashscope.aliyuncs.com/api/v1`。
- LLM：`deepseek-flash`，`https://api.deepseek.com`。

账号地域不同，应在设置中填写该地域或业务空间的官方 API 基础地址。程序只允许把模型 Key 发给对应供应商的 HTTPS 域名。配置项须保存 Key 本身，不要添加 `Bearer ` 前缀。

没有 OSS 时，仍可导入 UTF-8 TXT 或标准转写 JSON，直接使用 DeepSeek 整理；录音转写任务会列出缺少的配置，不会默默换到其他平台。

## 使用

1. 在「导入面试」上传 MP3、M4A、WAV、DOCX、Markdown、TXT 或 JSON。
2. 录音按需选择普通立体声合并，或双方独立声道分别识别。两条声道分别计费。
3. 在「处理任务」查看阶段，支持取消和失败后从检查点重试。
4. 在「问答知识库」搜索问题、回答、标签、标题，按岗位筛选。
5. 在「面试详情」对照原文、点击时间回听、编辑摘要、修改角色显示名、下载笔记及恢复历史版本。

`samples/interview.txt` 是可直接导入的虚构面试文本。导入文本不会编造时间戳或音色身份，因此纯 TXT 不提供回听按钮。

标准 JSON 示例：

```json
{
  "schema_version": "1.0",
  "duration_ms": 2000,
  "segments": [
    {"id": "s1", "text_raw": "什么是幂等？", "speaker_id": "A", "start_ms": 0, "end_ms": 900},
    {"id": "s2", "text_raw": "重复调用产生相同业务结果。", "speaker_id": "B", "start_ms": 1000, "end_ms": 2000}
  ]
}
```

## 数据与恢复

默认目录：`%LOCALAPPDATA%/InterviewAgent/`。可通过启动前设置 `DATA_DIR` 更换；同一个数据目录只运行一个 Worker。

- `app.db`：任务、费用预留、问答和版本。
- `media/`：原始录音。
- `transcripts/`：标准转写。
- `jobs/`：预处理音频、供应商原文、分块检查点。
- `notes/<面试 ID>/interview.md`：当前版本笔记。
- `notes/<面试 ID>/<版本 ID>.md`：历史版本笔记。
- `backups/`：界面触发的一致性数据库备份。

数据库是编辑的权威来源。直接修改 Markdown 不会写回数据库；外部打开笔记可通过相对链接访问原录音，当前版本尚未实现独立 Obsidian vault 打包。

界面备份按钮只备份数据库。完整迁移请先暂停使用、关闭启动程序，再复制整个数据目录；恢复时同样先关闭程序。运行中不要只复制 `app.db` 而忽略 WAL 文件。

远端提交已返回任务 ID 时，重启只查询原任务。提交超时且无法确认云端是否创建任务时，程序禁止自动重提，需先在控制台确认；这种情况可以保留任务记录并重新导入同一录音创建显式的新任务，注意避免重复计费。

## 问答输出过长的自动恢复

默认按最多 2200 字符、48 个转写片段分批整理（字符不是 Token 数），每次输出上限 8192 Token。云端明确返回 finish_reason=length 时，自动将当前未完成批次二分，并保存拆分计划；最多拆分 4 层，单片段无法再拆时明确失败，继续受调用预算限制。已成功批次保持原顺序与问题 ID，不重新调用；旧版任务已有成功批次时保留旧分组，仅拆分尚未完成部分。内容过滤不会触发拆分，资源不足或生成中断按有限重试处理。终止原因、请求 ID 和实际用量均保存，未完成的 JSON 不会发布到知识库。

2026-10-15 补充验证：70 项自动化测试通过；一场已转写为 192 个片段、5678 字的失败任务，复用原转写分 4 批恢复成功，生成 23 条问答、3 条追问。所有片段均有归属，未增加语音识别调用；10 条问答带待核对标记，来源有效不代表语义已经人工审核。

## 任务实时进度与计时

处理任务页每 3 秒自动刷新，展示流程阶段进度、问答已保存片段进度、当前批次和模型请求等待时间。转写阶段显示云端状态及已完成声道数；云端没有提供的百分比和剩余时间不会估算展示。流程进度按阶段划分，不代表耗时比例；自动拆分时，片段进度仍按已保存来源计算。

提交、首次开始、结束时间和当前/最后阶段耗时保存到数据库，完成或失败后历时停止增长，重启后保留。总历时从首次开始计入重试等待、暂停和程序关闭的时间；手动重试不清空首次开始时间。数据库迁移为 user_version=3，旧任务按事件/调用记录估算开始时间并明确标注，无法恢复的时间显示“—”。

## 直接导入面试问答文档

在「导入面试」选择 .docx 或 UTF-8 .md 文件，填写标题并点击「开始整理」。文档最多 10 MB，读取后直接进入 DeepSeek 问答整理与来源校验，跳过 OSS 和语音识别；仍会产生文本模型调用费用。

Word 支持正文段落和问题/回答表格，按文档顺序读取；例如逐段写「问题：什么是幂等？」与「回答：重复执行与执行一次效果相同。」，也可以使用两列表格，无需固定模板。原文件随转写文字保存在本地，可在「面试详情」下载原始问答文档，删除面试时一并清理。

仅提取文字，不识别图片/扫描件，不读取批注、页眉页脚；不生成录音时间戳或回听入口。旧 .doc 或受密码保护的文件请先另存为普通 .docx。空白、损坏及纯图片文档会给出明确提示，不创建任务。文档内容经提取、整理及来源校验后保存到知识库，完成后仍建议人工核对。


## Windows EXE 本地版

构建后可直接双击 `dist/interview-agent/interview-agent.exe`，无需另装 Python 或 FFmpeg。请保留整个目录与 `_internal`，也可解压 `dist/interview-agent-windows-x64.zip` 使用。程序包不包含密钥和个人知识库，云端模型仍需联网和系统环境变量。控制窗口可打开页面、日志和停止服务。

构建：在项目虚拟环境安装 `requirements-build.txt`，运行 `build-windows.ps1`，会先测试再生成应用目录、ZIP 与 SHA-256 校验文件。详见 [Windows 本地程序使用说明](docs/windows-exe.md)。当前通过 98 项自动化测试，EXE 在独立中文数据目录、禁用云端密钥且 PATH 无 Python 的环境中通过页面、工作进程和内置音频转换验证；该验证未产生云端调用。


## 面试高分答案

在「问答知识库」或「面试详情」展开每题的「面试高分答案」，点击生成即可结合岗位、问题、原答和相关原文生成练习参考。答案包含作答示例、得分要点、原答改进建议、可能追问及需要按个人情况补充的内容。模型不能保证高分；个人经历、项目及指标需真实补充。

生成按题触发，每次调用一次 DeepSeek，使用现有系统环境变量和月预算预留；页面刷新不会自动调用。已有结果独立保存到 SQLite，可下载 Markdown，也会随面试笔记导出；重复点击受生成锁保护，失败保留上一版。只改标签/角色时沿用答案，问题、原答或相关来源变更后重新生成；删除面试会清理对应参考内容。数据库迁移到 user_version=4，升级 EXE 后再打开；旧版 EXE 不能读取升级后的数据库。升级前已有数据库备份仍保留。
